# Тест-кейсы для `check_active_users.sh`

## 📋 Описание
Скрипт `check_active_users.sh` проверяет активных пользователей, объединяя данные из трёх источников:
- `users.txt` — список логинов
- `logins.csv` — даты последнего входа
- `banned.json` — список заблокированных пользователей

Результат сохраняется в `active_users.csv`.

---

## 1. Проверка передачи и обработки формата данных

### 1.1 Файл `users.txt`

| № | Сценарий | Тип |
|---|----------|-----|
| 1.1.1 | Один логин на строку | ✅ Позитивный |
| 1.1.2 | Логины через запятую | ❌ Негативный |
| 1.1.3 | Валидные логины | ✅ Позитивный |
| 1.1.4 | Спецсимволы в логине | ❌ Негативный |
| 1.1.5 | Пустые строки в файле | ❌ Негативный |
| 1.1.6 | Пустой файл | ✅ Позитивный |
| 1.1.7 | Файл отсутствует | ❌ Негативный |

### 1.2 Файл `logins.csv`

| № | Сценарий | Тип |
|---|----------|-----|
| 1.2.1 | Стандартный CSV | ✅ Позитивный |
| 1.2.2 | Другой разделитель | ❌ Негативный |
| 1.2.3 | Логин совпадает с `users.txt` | ✅ Позитивный |
| 1.2.4 | Логин отсутствует в `users.txt` | ⚠️ Нейтральный |
| 1.2.5 | Дата в формате `YYYY-MM-DD` | ✅ Позитивный |
| 1.2.6 | Некорректный формат даты | ❌ Негативный |
| 1.2.7 | Заголовок `login,last_login` | ✅ Позитивный |
| 1.2.8 | Заголовок отсутствует | ❌ Негативный |
| 1.2.9 | Только заголовок | ✅ Позитивный |
| 1.2.10 | Файл отсутствует | ❌ Негативный |

### 1.3 Файл `banned.json`

| № | Сценарий | Тип |
|---|----------|-----|
| 1.3.1 | Валидный JSON-массив | ✅ Позитивный |
| 1.3.2 | Невалидный JSON | ❌ Негативный |
| 1.3.3 | JSON-объект вместо массива | ❌ Негативный |
| 1.3.4 | Пустой массив | ✅ Позитивный |
| 1.3.5 | Логин в `banned.json` не в `users.txt` | ⚠️ Нейтральный |
| 1.3.6 | Файл пустой (0 байт) | ❌ Негативный |
| 1.3.7 | Файл отсутствует | ❌ Негативный |

### 1.4 Передача аргументов скрипту

| № | Сценарий | Тип |
|---|----------|-----|
| 1.4.1 | Корректный вызов | ✅ Позитивный |
| 1.4.2 | Нет аргументов | ❌ Негативный |
| 1.4.3 | Меньше 3 аргументов | ❌ Негативный |

## 2. Проверка бизнес-логики фильтрации

### 2.1 По статусу бана

| № | Сценарий | Тип |
|---|----------|-----|
| 2.1.1 | Пользователь в `banned.json` | ✅ Позитивный |
| 2.1.2 | Пользователь НЕ в `banned.json` | ✅ Позитивный |
| 2.1.3 | Все пользователи заблокированы | ✅ Позитивный |
| 2.1.4 | Никто не заблокирован (`[]`) | ✅ Позитивный |

| 2.2.4 | Заходил > 30 дней назад | ✅ Позитивный |

### 2.3 По наличию записи в `logins.csv`

| № | Сценарий | Тип |
|---|----------|-----|
| 2.3.1 | Логин есть в `logins.csv` | ✅ Позитивный |

| 2.3.3 | Логин в `logins.csv`, но не в `users.txt` | ⚠️ Нейтральный |

| № | Сценарий | Тип |

| 2.4.2 | Не забанен, но заходил > 30 дней | ✅ Позитивный |
